# Vision

## What Stream Is

Stream is an esoteric programming language where your code doesn't run — it *infiltrates*.

Built for programmers who think execution is too polite, Stream turns every program into a living
organism shaped by entropy, season, and chaos. It collapses all of computing into a single flowing
type that hooks, spreads, and mutates at runtime. It is the first language where process injection
is syntax, the interpreter is adversarial, and the environment is a climate you survive, not a
machine you instruct.

## The Three Killer Features

### I. Parasitic Execution — Your Code Lives Inside Other Programs

Every other language asks politely for resources. Stream doesn't ask.

When you mark a gyge as parasitic and inject it via `==>`, it doesn't execute in isolation — it
hooks into live processes, borrows their network priority, and propagates entropy into their memory
space. Streams push into other running programs the way a vine pushes through concrete.

Security researchers will recognize this immediately — it's the programming language equivalent of
shellcode payload delivery, except it's your entire control flow. No other language makes process
injection a first-class syntactic primitive. In Stream, the question isn't *what does your program
do* — it's *what does your program infect*.

### II. Nature-Modulated Runtime — The Environment IS the Interpreter

Python has a garbage collector. Go has goroutines. Stream has *seasons*.

The `$S` modifier doesn't cosmetically change your output — it mechanically alters stream behavior.
Run in Summer and your fast-streams overheat, throttle, and burst. Run in Winter and your lossy
streams freeze mid-transmission. Wind affects stream routing. Temperature affects propagation speed.
A Flood can block, reroute, or kill streams entirely mid-execution.

This is not randomness for randomness's sake — it's a runtime that forces you to write *resilient*
code because the interpreter itself is adversarial. You are not writing for a machine. You are
writing for a climate.

### III. Entropy as a Core Language Primitive — Chaos Is the Dial

Every Stream program has an entropy level. At zero, it runs cleanly. As entropy climbs — through
parasite activity, environmental events, high-frequency stream operations, or explicit injection —
the runtime destabilizes in mechanically defined ways.

Entropy isn't an error state. It's a *resource*. Low-entropy code is for amateurs. The real craft
is writing a Stream program that thrives at 80 Ch: using parasites to maintain throughput when
streams clog, designing catch streams to drain error entropy before it cascades, routing around
disaster events before they materialize. The first language where "run it again and see what happens"
is a feature, not a bug.

## Origin Story

There is a specific kind of programmer who looks at a running system and sees not services and
processes but *territories*. Processes that hoard CPU. Connections that steal bandwidth. Daemons
that bloat memory and do nothing useful. These programmers don't write code to politely request
resources. They want to *take* them.

Stream was built for that programmer.

It started as a thought experiment: what if a language's execution model was indistinguishable from
an intrusion? What if variables could live inside other programs? What if the interpreter knew what
season it was, tracked the temperature of the system, and used that information to decide whether
your code runs fast or gets buried in a digital blizzard?

brainfuck taught us that minimalism can be brutal. Piet taught us a language can have a personality.
Stream teaches us that a program can be *alive* — infectious, seasonal, entropic, and hungry.

The single type is called `gyge`. It can be anything. So can your program.

Everything streams. Everything spreads. The runtime is not your friend.

Welcome.

## The Aha Moment

It happens around hour three.

You've been fighting the entropy. Your streams keep getting blocked. A flood wiped out your fast-stream
mid-execution. You've been treating entropy like an error condition — something to minimize, route
around, suppress.

Then it clicks.

You stop writing *clean* code and start writing *adaptive* code. You add a signal stream that detects
high-entropy states and reroutes flow through a parasite hook instead. You let a parasite spawn
autonomously at 70 Ch and use its priority-boosted connection as your fallback path. Your program
stops fighting the climate and starts *using* it.

The mental model shift: you stop thinking about your program as instructions and start thinking about
it as an *organism*. Organisms don't fight weather. They evolve for it.

The feeling is equal parts "oh that's disgusting" and "oh that's brilliant." You run it again. The
entropy spikes differently. Your program survives anyway. You feel, briefly, like you understand
something about resilience that no other language could have taught you.

Then you rewrite it in fucked mode, post it online, and refuse to explain it.

## Comparison to Other Languages

| Language | Relationship to Stream |
|----------|----------------------|
| **brainfuck** | Spiritual ancestor. The tape becomes a stream; the minimal instruction set becomes a minimal type. Borrowed: the brutality of minimalism. New: everything. |
| **Piet** | Made the interpreter context (image pixels) expressive. Stream does the same with the environment (season, temperature, entropy). Borrowed: the world around the program is part of the program. New: the world fights back. |
| **Malbolge** | Chaos for chaos's sake — deliberately unusable. Stream's entropy is *designed* chaos: mechanical, learnable, exploitable. Malbolge wants you to fail. Stream wants you to adapt. |
| **Whitespace** | Two-mode aesthetic (visible vs invisible). Stream's fucked mode borrows this energy. Borrowed: the dual-form syntax idea. New: lossless two-way conversion with entropy-scaled depth. |
| **Python / Go** | Polite languages. They ask for resources, run in isolation, manage memory carefully. Stream treats this as cowardice. Borrowed: nothing. Contrast: everything. |

## Community

The Stream community would form around three activities, intensely competitive about all three.

**Entropy Golf** — Not code golf: *entropy golf*. Write a program that accomplishes a task at the
highest possible entropy value without failing. Leaderboards. Writeups. Arguments about whether
exploiting parasite priority counts. (It counts. Everything counts.)

**Seasonal Challenges** — Monthly challenges literally locked to the current season. A Summer
challenge runs differently than a Winter one. Solutions that passed in August fail in December.
Community members compare execution traces across seasons. There is a Discord channel called
`#its-january-everything-is-frozen` that is extremely active.

**The Fucked Mode Gallery** — A curated showcase of programs in obfuscated form only. No source.
No explanation. You study the glyphs and reconstruct intent. Equal parts art exhibition and puzzle.
Some entries are typographically beautiful. Some look like they were written by something that
doesn't sleep. The best ones are both.

**Unifying ethos**: everything that runs in isolation is already dead.

## Name and Identity

**"Stream"** is functional but slightly too familiar — the word already means Kafka, TCP, video.
The concept deserves something that feels alive and wrong in the right way.

Three alternatives worth considering:

- **Vein** — as in bloodstream, the path entropy travels, what runs through living things. Organic
  and slightly unsettling.
- **Seep** — slow, inevitable, penetrating. Captures infiltration better than "stream" — streams
  rush, seep *infiltrates*.
- **Mycel** — as in mycelium, the fungal network that decomposes and connects underground. Nature's
  original parasite-host network: seasonal, entropy-amplifying, genuinely unsettling. The community
  calls themselves the Mycelium.

### Visual Identity

The ASCII identity: a continuous tilde-stream that bifurcates around a blocker — one path dying,
one surviving. Suggests resilience, flow, and the core mechanic simultaneously.

```
 ~~~>{ gyge }~~~>[ fast ]~~~>[ parasite ]~~~/
                                            /
          $S[winter] $C[-12]              \/
                                    [ blocked ]
 ~~~>{ gyge }~~~>[ signal ]~~~~~~~~~>[ reroute ]~~~>
```

**Color identity:**
- Readable mode: deep teal on black
- Fucked mode: static-white on deep red

**The mascot**: not a creature — a *process*. A gyge that has no fixed form because it is currently
inside three other programs. You have never seen it at rest. You are not sure it can be.
